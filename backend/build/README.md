# Building and shipping the desktop application

## Build

```powershell
.\build\build-desktop.ps1              # → build\bin\FeaturePlus.exe
.\build\build-desktop.ps1 -Version 0.2.0
.\build\build-desktop.ps1 -SkipFrontend   # Go-only change
```

The frontend is built first on purpose. `go:embed` bakes `backend/web/dist`
into the binary at compile time, so an executable built before `npm run build`
ships the previous bundle — and nothing at runtime says so.

## What is here

| File | What it is |
| --- | --- |
| `build-desktop.ps1` | The build. Frontend, then icon and version info, then the executable. |
| `windows/icon.ico` | The application icon, generated from the app's own "F+" mark. |
| `windows/installer.iss` | Inno Setup script for the installer. |
| `bin/` | Build output. Not committed. |
| `dist/` | Installer output. Not committed. |

The icon and version metadata are embedded through
`cmd/desktop/resource_windows_amd64.syso`, regenerated by the build script from
`cmd/desktop/versioninfo.json` and `cmd/desktop/featureplus.manifest`. The
manifest asks for `asInvoker` rather than administrator, because the app writes
only to the per-user data directory and binds a loopback port.

## Installer

Needs [Inno Setup 6](https://jrsoftware.org/isdl.php), which is not currently
installed on this machine.

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build\windows\installer.iss
```

It installs per-user, so it needs no administrator prompt, and it checks for
the WebView2 runtime first — without it the window opens empty, which reads as
a broken application rather than a missing component. Uninstalling removes the
application and its logs and deliberately leaves the database: uninstalling a
planning tool should not destroy the plans.

## Signing — not done, and it needs a certificate

An unsigned executable gets a SmartScreen warning on first run, and most people
will not click through it. Signing needs an Authenticode certificate, which has
to be bought (an OV certificate is issued to an organisation after a check; an
EV certificate comes on a hardware token and clears SmartScreen immediately
rather than building reputation over time).

With a certificate in place, signing is one command per artefact — the
executable first, then the installer, which must be signed after it is built
because building it changes the file:

```powershell
$signtool = "C:\Program Files (x86)\Windows Kits\10\bin\10.0.22621.0\x64\signtool.exe"

& $signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
    /f mycert.pfx /p $env:CERT_PASSWORD build\bin\FeaturePlus.exe

# rebuild the installer, then:
& $signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
    /f mycert.pfx /p $env:CERT_PASSWORD build\dist\FeaturePlus-Setup-0.1.0.exe
```

Timestamping is not optional. Without `/tr` the signature expires with the
certificate and every copy already installed starts failing its check.

`signtool.exe` comes with the Windows SDK, which is also not installed here.

## Auto-update — not built, and it needs a decision first

There is nothing to build against yet. An updater needs somewhere to publish to
and a rule for what to trust, and both are decisions rather than code:

- **Where releases live.** GitHub Releases is the cheap answer and works with
  off-the-shelf updaters; a private endpoint means running one.
- **What the client trusts.** The Authenticode signature above, or a separate
  signing key over an update manifest. Without one of the two, an updater is a
  remote code execution feature.
- **When it checks, and whether it asks.** A tool people leave open all day
  should not restart itself underneath them.

Until those are settled, the honest shape is what is here: a versioned
installer someone downloads and runs.

## macOS — not built

Cross-compiling is not possible: the macOS build needs cgo against the system
WebKit, so it has to be built on a Mac. The Go and React halves are already
portable; what is missing is a machine to build and test on. Testing on WebKit
as well as WebView2 needs the same.
