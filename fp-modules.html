FeaturePlus — Feature → Plan → Code Map

Maps features / subfeatures (up to 4 nesting levels) to a reusable plan (the high-level intent used while building), and records the concrete code artifacts that implement it. Source of truth = actual code (Go backend, React frontend, CLI, Python tools/map).

Use it two ways — (1) reverse map: what exists and where it lives; and (2) forward template: when adding a feature, pick a plan verb then fill column 3 with the table/column, component, module, or function you will touch.

How to extend this map (forward use)

  1. Name the feature path Domain › Feature › Subfeature › detail (1–4 levels).
  2. Pick a plan verb from the vocabulary table.
  3. In column 3, write the exact table+column, component file, module path, or path:Function you added or changed — mirroring the existing rows.
  4. One feature may span several rows (e.g. ADD_DB_COLUMN + ADD_FUNCTION + CHANGE_UI_COMPONENT).
